# nightly-notes

This branch holds notes, not code: the priorities and logs of the nightly agents that work on our fork of FilmCraft (`iannitram/filmcraft`, tracking `storytold/filmcraft`).

| File | Owner | What |
|---|---|---|
| `WISHLIST.md` | Ian | Our priorities, in order. The agents read it every run and never edit it |
| `STATE.md` | the agents | Review cursor, open threads, design notes, our branches and their status |
| `SETUP.md` | shared | What the cloud sandbox can and can't do |
| `nightly/YYYY-MM-DD.md` | the agents | One log per night (all of that night's routines append to the same file) |
